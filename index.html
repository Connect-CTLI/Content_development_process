PDD Course Draft Sorter

Set up the course, drop in the course draft (.docx) and get a snippet for every resource, with recommended items to add. Then copy the rows and item codes straight into the Resource Creation Sheet (T06). The document is read in your browser and never uploaded.

1 Set up the course and add the draft

The set-up builds the item codes the same way the Resource Creation Sheet does: programme + type + _ + main source + . + source element. Use the Course Draft template: Heading 1 for each module, Heading 2 for each topic, and bold lines for activities such as "Assignment:", "Reflective post:" or "Knowledge check:".

Drop the .docx here, or click to choose it Word, or Google Docs downloaded as Microsoft Word (.docx). The file is read in this browser and never uploaded.

2 Review the snippets and recommended items

Each row is one resource with its snippet of content. Untick anything you will not build, change a type with the dropdown, and add a recommended item with one click. Flags show reviewer comments, notes in [brackets] and gaps in the draft.

3 Copy into the Resource Creation Sheet

  1. Click Copy rows for Resource Creation.
  2. In T06, open Resource Creation, click the first empty cell in column B and paste. Column A builds the same item codes shown here.
  3. Click Copy questions and paste into the first empty row of the Question Bank (column A). The Design Blueprint and QA Review tabs update by themselves.
